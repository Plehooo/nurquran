# Changelog

## 1.0.0 — initial source package

- Native Kotlin/Jetpack Compose project and bottom-navigation shell.
- Quran catalog and Arabic/Indonesian surah reader with structural and verse-index checks.
- Hadith book/page API client with pagination payload validation.
- AlAdhan prayer timetable using method 20, private cache, manual/last-known location, and notification-only reminders.
- Qibla bearing calculation, settings, bookmarks, API cache clearing, and privacy notes.
- Unit-test source files and GitHub Actions workflow for validation/debug artifact and optional signed release artifact.

Build, lint, test, device installation, and signed APK status are pending CI/runtime verification.
