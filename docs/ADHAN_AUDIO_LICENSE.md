## Audio Jiharkah pilihan pengguna

Untuk memakai rekaman Jiharkah tertentu, pilih file yang legal untuk digunakan dari penyimpanan perangkat melalui **Pengaturan → Pilih audio Jiharkah dari HP**. File disalin ke penyimpanan privat aplikasi, dipakai otomatis untuk alarm berikutnya, dan dapat diuji melalui tombol **Tes audio adzan**. Tidak ada rekaman pihak ketiga yang tidak jelas izinnya dibundel dalam repository.
