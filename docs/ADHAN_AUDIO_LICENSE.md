# Audio adzan — attribution and license

The app downloads this audio at first launch when an internet connection is available:

- **Title:** Beautiful adhan.ogg
- **Creator:** Adam-synagda
- **Source:** https://commons.wikimedia.org/wiki/File:Beautiful_adhan.ogg
- **License stated by uploader:** Creative Commons CC0 1.0 Universal Public Domain Dedication
- **Direct media URL used by the app:** https://upload.wikimedia.org/wikipedia/commons/b/b0/Beautiful_adhan.ogg

The file is not vendored into this repository. If the source URL changes or the download is unavailable, the alarm player falls back to the device's default alarm sound.
