This source project links to third-party services; it does not include or redistribute a copy of their Quran, translation, hadith, or prayer-time dataset.

- **AlQuran Cloud API** — https://alquran.cloud/api. API service and edition terms must be followed; verify the exact rights/attribution requirements for `quran-uthmani` and `id.indonesian` before public distribution.
- **Hadis API Indonesia** — https://github.com/renomureza/hadis-api-id. The reviewed repository README identifies an MIT license for the API repository. Dataset origins/attribution may have separate conditions; review them before redistribution.
- **AlAdhan Prayer Times API** — https://aladhan.com/prayer-times-api. Follow the published API terms and attribution requirements; do not infer dataset ownership/licensing from the endpoint alone.
- **AndroidX, Jetpack Compose, Retrofit, OkHttp, Gson, Kotlin Coroutines, desugar_jdk_libs and JUnit** are third-party dependencies under their respective licenses. Their licenses should be generated/reviewed for the final APK before commercial publication.

No claim is made here that the remote datasets are all public domain or that this is a complete third-party notice. Confirm source-specific text and redistribution rights with the upstream providers.
